# Autofocus
Autofocus has been widely used in biological imaging to free users from tedious and repetitive works. However, due to background noise and different combination of sample types and staining method, the stability and reproducability of autofocus method is a mean challenge. Therefore, we developed a fast and accurate autofocus method based on enhanced mountain climbing search algorithm which can be broadly used in different senarios.
